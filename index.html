Xiaomi LYWSD03MMC Kullanım Kılavuzu

Web Bluetooth ile Nasıl Bağlanılır?

  1. Bilgisayarınızda veya telefonunuzda Bluetooth'un açık olduğundan emin olun.
  2. Google Chrome, Microsoft Edge veya Opera gibi Web Bluetooth destekli modern bir tarayıcı kullanın.
  3. "Cihaza Bağlan" butonuna basın.
  4. Tarayıcı açılır penceresinde LYWSD03MMC cihazınızı seçip "Eşle / Bağlan" butonuna tıklayın.

Cihazın Dahili Geçmiş Arşivi (Flash Memory)

Xiaomi Mijia termometresi kendi dahili çipinde saatlik min/maks sıcaklık ve nem kayıtlarını depolar. Cihaza bağlandıktan sonra "Geçmişi İndir" butonuna bastığınızda, cihazın EBE0CCBC GATT karakteristiği üzerinden geçmiş kayıtlar taranarak çekilir ve grafiklerde geriye dönük görüntülenir.

7/24 Arka Planda Kayıt (Python Tracker)

Tarayıcıyı açık tutmak istemiyorsanız, projedeki tracker.py Python servisini çalıştırarak verileri arka planda SQLite ve CSV dosyasına sürekli kaydedebilirsiniz: 

pip install -r requirements.txt
python tracker.py --scan
python tracker.py --history
